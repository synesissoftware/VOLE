# FAQs: <!-- omit in toc -->


## Q1: "Is VOLE still maintained?"

No. **VOLE** **0.7.7** is the final release. The project is frozen and
obsolete.


## Q2: "How do I install VOLE?"

See [INSTALL.md](./INSTALL.md). **VOLE** is header-only and needs **STLSoft**
1.9.130 or later on the include path.


## Q3: "What should I use instead?"

Prefer native MSVC COM / Automation facilities for new work.
